# Kanban

Учебный проект на React

## Основные функции

### Авторизация

- **Регистрация**: создайте аккаунт по электронной почте и паролю.
- **Вход**: войдите в уже существующий аккаунт.
- **Выход**: через меню пользователя (в правой части шапки) → «Выйти».
- Без входа доступ к доске закрыт — сначала нужно авторизоваться.

### Работа с задачами

#### Создание задачи
- Нажмите **«Создать новую задачу»** в шапке.
- Заполните по желанию **название**, **описание**, выберите **дату** и **категорию**.
- Нажмите **«Создать задачу»** — задача появится на доске.

#### Просмотр задачи
- Откройте карточку задачи (через кнопку с тремя точками на карточке).
- Откроется окно с деталями: описание, дата и текущий статус.

#### Редактирование задачи
- В окне задачи нажмите **«Редактировать задачу»**.
- Можно изменить:
  - **описание**,
  - **дату**,
  - **статус** (перевод между колонками/этапами).
- Нажмите **«Сохранить»**, чтобы применить изменения, или **«Отменить»**, чтобы вернуть прежние данные.

#### Удаление задачи
- В окне задачи нажмите **«Удалить задачу»**.
- Подтвердите удаление — задача будет удалена с доски.

# Дополнительные функции

## Пользовательские категории

Пользовательские категории позволяют настраивать и расширять список категорий задач в рамках темы.

### Возможности

- добавление новых категорий;
- редактирование существующих категорий;
- переопределение базовых категорий темы;
- удаление пользовательских категорий;
- импорт и экспорт категорий в формате JSON.

### Базовые категории

- Базовые категории всегда присутствуют в теме.
- Их нельзя удалить, но можно изменить или сбросить к исходному состоянию.
- При импорте категории с совпадающим названием переопределяют базовые.

### Валидация

Для категорий действуют следующие правила:

- название категории не может быть пустым;
- названия категорий должны быть уникальны;
- каждая категория должна быть связана с существующим стилем оформления.

### Импорт и экспорт

- Поддерживается импорт категорий из JSON-файла.
- При импорте выполняется автоматическая проверка данных.
- Категории с ошибками импортируются, но требуют ручного исправления.
- Экспорт сохраняет текущие категории в файл для повторного использования.

Если категория содержит ошибку:

- она подсвечивается в списке;
- сохранение темы блокируется;
- пользователь видит сообщение с количеством проблемных категорий.

Категория считается исправленной только после подтверждения пользователем.

### Сохранение темы

- Сохранение доступно только при отсутствии ошибок.
- Некорректные данные не могут быть сохранены в теме.

### Принципы

- пользователь всегда видит, что требует исправления;
- ошибки не исчезают без подтверждения;
- невозможно сохранить некорректные данные случайно.

## Перетаскивание задач (Drag & Drop)

В приложении можно **перетаскивать задачи мышью или пальцем** — это помогает быстрее наводить порядок на доске.

### Как пользоваться

- **Зажмите карточку задачи** и перетащите её в нужную колонку (например, из «Нужно сделать» в «В работе»).
- **Отпустите карточку** — задача сразу окажется в выбранной колонке.
- На телефоне перетаскивание работает так же: **нажмите и удерживайте**, затем переместите.

### Что это даёт

- проще менять статус задачи без лишних кликов;
- быстрее распределять задачи по этапам;
- удобнее работать и на компьютере, и на мобильных устройствах.

## Уведомления (React-Toastify)

В проекте используются всплывающие уведомления на базе **react-toastify**. Они помогают быстро сообщать пользователю о результате действий (успех/ошибка/информация) без блокирующих модальных окон.

### Где используются

- создание/редактирование/удаление сущностей (задачи, категории, тема);
- импорт/экспорт JSON;
- системные ошибки (например, сбой чтения файла или проблемы с сохранением).

### Типы уведомлений

- **success** — действие выполнено успешно (например, «Категория сохранена»);
- **error** — ошибка, требующая внимания (например, «Не удалось импортировать файл»);
- **info** — нейтральная подсказка (например, «Отправляются данные...»).

### Поведение

- уведомления автоматически скрываются через заданный интервал;
- несколько уведомлений аккуратно складываются в очередь;
- уведомления не мешают работе и не блокируют интерфейс.

## Светлая и тёмная тема

Приложение поддерживает **светлую** и **тёмную** тему оформления. Переключение темы влияет на основные цвета интерфейса (фон, текст, карточки, элементы управления), а также на цвета уведомлений. Если нет сохранённых данных об используемой теме, то выбирается тема на основе системных настроек.

### Переключение темы

- пользователь может переключать тему в интерфейсе (переключатель/настройки);
- выбранная тема сохраняется в настройках браузера и применяется при следующем открытии приложения (если включено сохранение настроек).

### Стилизация уведомлений под тему

Уведомления **React-Toastify** автоматически подстраиваются под текущую тему приложения:

- в светлой теме используются светлые фоны и контрастный текст;
- в тёмной теме — тёмные фоны и светлый текст;
- цветовые акценты (success/error/info) остаются различимыми в обеих темах.

### Принципы

- единый визуальный стиль во всём приложении;
- достаточная контрастность и читаемость в обеих темах;
- уведомления не «выбиваются» из темы и соответствуют текущему оформлению.
