# Kanban

Учебный проект на React

# Дополнительные функции

## Пользовательские категории

Пользовательские категории позволяют настраивать и расширять список категорий задач в рамках темы.

### Возможности

- добавление новых категорий;
- редактирование существующих категорий;
- переопределение базовых категорий темы;
- удаление пользовательских категорий;
- импорт и экспорт категорий в формате JSON.

---

### Базовые категории

- Базовые категории всегда присутствуют в теме.
- Их нельзя удалить, но можно изменить или сбросить к исходному состоянию.
- При импорте категории с совпадающим названием переопределяют базовые.

---

### Валидация

Для категорий действуют следующие правила:

- название категории не может быть пустым;
- названия категорий должны быть уникальны;
- каждая категория должна быть связана с существующим стилем оформления.

---

### Импорт и экспорт

- Поддерживается импорт категорий из JSON-файла.
- При импорте выполняется автоматическая проверка данных.
- Категории с ошибками импортируются, но требуют ручного исправления.
- Экспорт сохраняет текущие категории в файл для повторного использования.

Если категория содержит ошибку:

- она подсвечивается в списке;
- сохранение темы блокируется;
- пользователь видит сообщение с количеством проблемных категорий.

Категория считается исправленной только после подтверждения пользователем.

---

### Сохранение темы

- Сохранение доступно только при отсутствии ошибок.
- Некорректные данные не могут быть сохранены в теме.

---

### Принципы

- пользователь всегда видит, что требует исправления;
- ошибки не исчезают без подтверждения;
- невозможно сохранить некорректные данные случайно.
